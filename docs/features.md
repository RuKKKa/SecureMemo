# SecureMemo 機能仕様書

本ドキュメントでは、`SecureMemo` に搭載されている各機能の詳細仕様と操作方法について解説します。

---

## 1. リッチテキストメモ編集 (WYSIWYGエディタ)

直感的な操作でテキスト装飾ができる「見たまま編集（WYSIWYG）」エディタを搭載しています。

- **書式装飾ツールバー**:
  - **太字 (`Bold`)**: 選択中のテキストを太字にします（ショートカット: `Ctrl + B`）
  - **斜体 (`Italic`)**: 選択中のテキストを斜体にします（ショートカット: `Ctrl + I`）
  - **下線 (`Underline`)**: 選択中のテキストに下線を引きます（ショートカット: `Ctrl + U`）
  - **見出し (`H1` / `H2`)**: 選択行を見出しスタイルに変換
  - **リスト (`箇条書き` / `番号付き`)**: リスト形式での整理
  - **引用 (`Quote`)**: 引用スタイルのブロックを作成
- **リアルタイム自動保存**:
  - タイトル・本文の入力時に自動保存が即座に動作し、保存ボタンを押さずに安全にデータが保持されます。
- **全画面フルビュー設計**:
  - メモを開くと画面全体がエディタになり、執筆に専念できます。「← 戻る」ボタンでスムーズに一覧画面へ復帰します。

---

## 2. メモ一覧 & プレビュー表示

- **単一ビュー型レイアウト**:
  - 一覧画面とエディタ画面を明確に切り替えるフルスクリーン設計。
- **リッチ装飾プレビュー**:
  - 一覧カード上でも太字・斜体・リストなどの装飾がそのまま反映され、メモの内容が一目で分かります。
- **ピン留め機能**:
  - 重要なメモを一覧の最上部に固定表示。
- **インクリメンタル検索**:
  - タイトルおよび本文から、文字入力に合わせてリアルタイムで絞り込み検索。
- **更新日時の自動記録**:
  - 最終更新日時が自動的に記録・表示されます。

## 3. 暗号化ロック機能 (セキュリティ)

Web標準の暗号化APIを活用した、クライアント完結型のセキュアなロック機能です。

- **暗号化アルゴリズム**:
  - **暗号化方式**: `AES-GCM 256bit`
  - **鍵導出**: `PBKDF2`（SHA-256、100,000回ストレッチング + 16バイトのソルト）
  - **初期化ベクトル (IV)**: 暗号化ごとに毎回異なる12バイトの暗号論的乱数を生成
- **プライバシー保護**:
  - ロックされたメモは一覧上でも本文が伏字となり、「暗号化保護」バッジが表示されます。
  - 正しいPINコードを入力するまで復号されず、第三者による閲覧を防止します。
- **デバイス最適化PIN入力UI**:
  - **スマホ・タッチデバイス**: 親指で押しやすいオンスクリーンキーパッド（1〜9, 0, クリア, 削除）を表示。
  - **PC環境**: キーパッドを自動非表示にし、キーボード直接入力および Enter キーでの決定に対応。

## 4. フォルダ分類 & ナビゲーション

- **フォルダ管理**:
  - フォルダの自由な作成、カラーラベル（全6色）の選択、名称変更、削除。
- **所属フォルダ変更**:
  - メモ編集画面の上部から所属フォルダをワンクリックで切り替え。
- **安全設計**:
  - フォルダを削除しても配下のメモは削除されず、「未分類」として保持されます。
- **サイドバーフィルター**:
  - 「すべてのメモ」「ロック中」「未分類」「各カスタムフォルダ」での絞り込み表示。

---

## 5. 外観設定 & データバックアップ

- **カラーテーマ**:
  - ブルーを基調とした爽やかでモダンなUIデザイン。
- **ダークモード**:
  - ライトモード / ダークモード / OS端末設定連動（System）の3パターンに対応。
- **データバックアップ & 復元**:
  - すべてのメモとフォルダデータを JSON ファイルとしてエクスポート（ダウンロード）。
  - JSON ファイルを読み込んでデータを復元（インポート）。
  - 初期サンプルデータへのリセット機能。
- **モバイル対応**:
  - スライドイン式サイドバードロワー、右下に常駐する押しやすい新規作成ボタン（FAB）。
